数字时钟设计

2024-01-10 · 51 单片机 / Proteus

设计内容

  1. 选择 51 单片机，晶振采用 12MHz。
  2. 系统可以按“秒”进行计时。
  3. 数字时钟可以显示小时（00～23）、分钟（00～59）和秒（00～59）。
  4. 可通过按键 K1 来选择设置“小时”“分钟”和“秒”。设置时可通过“加”和“减”按键（K2、K3）来调整时间；设置过程中时钟停止计时。
  5. 无键按下 3 秒钟后，自动进入时钟的计时和显示。

return x, self.y[i]

class ShallowRegressionLSTM(nn.Module):
def __init__(self, num_sensors, hidden_units):
super().__init__()
self.num_sensors = num_sensors # 特征数量
self.hidden_units = hidden_units
self.num_layers = 1
self.lstm = nn.LSTM(
input_size=num_sensors,
hidden_size=hidden_units,
batch_first=True,#（批，序列，特征）
num_layers=self.num_layers
)
self.linear = nn.Linear(in_features=self.hidden_units,
out_features=1)
def forward(self, x):#初始化 h0 和 c0 为批大小作为第二维度
batch_size = x.shape[0]
h0 = torch.zeros(self.num_layers, batch_size,
self.hidden_units).requires_grad_()
c0 = torch.zeros(self.num_layers, batch_size,
self.hidden_units).requires_grad_()
_, (hn, _) = self.lstm(x, (h0, c0))
out = self.linear(hn[0]).flatten() #线性输出层，回归任务单输出单元
# hn 的第一维是层数（在上面设为一）

return out
